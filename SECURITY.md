# Security policy

Metrik is a public production application, while its GroundTruth research
pipeline handles private source data. Please avoid sharing credentials, raw
crawl data, personal data, or exploit details in public issues.

## Reporting a vulnerability

Use GitHub's **Report a vulnerability** option in the repository Security tab
to send a private report. If that option is unavailable, contact the repository
owner privately through GitHub and ask for a secure reporting channel. Do not
open a public issue for an unpatched vulnerability.

Include the affected component, impact, steps to reproduce, and any suggested
mitigation. Please allow time for investigation and a fix before public
disclosure. There is no published response-time guarantee.

## Scope

Reports about the public Metrik site/API, deployment configuration, dependency
risks, and handling of research data are in scope. Reports should concern a
security impact; general bugs and feature requests belong in regular issues.
