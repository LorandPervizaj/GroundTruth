# Methodology v1.0.0 (frozen)

**Status:** Current as of 2026-06-09. When superseded, this file is immutable.

## Statistical methods

- Central tendency: **median** (primary), mean (secondary)
- Dispersion: **IQR**, **MAD**, standard deviation
- Uncertainty: **bootstrap percentile CI** (5000 resamples, seed=42)
- Comparison: `compare_medians()` with difference CI
- Stability: `assess_stability()` — stable / moderately_stable / volatile

## Dataset confidence (v1)

```
score = parser_accuracy × coverage × diversity × completeness × sample_reliability
sample_reliability = min(1, √(n/100))
```

## Evidence grades

| Grade | Meaning |
|-------|---------|
| A | Manually verified |
| B | Benchmark-validated |
| C | Parser-derived with provenance |
| D | Exploratory |
| E | Hypothesis / interpretation |

## Provenance

Every parsed field records: rule_id, source, snippet, confidence_contribution.  
See `groundtruth.provenance` and `data/ontology/fields.json`.

## Confidence decomposition

Per-listing confidence = weighted sum of components: price, area, neighborhood, type, parser_certainty, normalization, validation.
